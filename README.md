Etch-A-Sketch Web App

Overview

A browser-based interactive drawing application that simulates the classic Etch-A-Sketch toy. Users can draw on a grid, adjust the grid size dynamically using a slider, select pen colors, and reset the canvas.

Features

Adjustable grid size (8x8 to 64x64) via slider.

Customizable pen color using a simple color picker.

Reset button to clear the grid and start fresh.

Responsive and performant grid rendering.

Technologies Used

HTML5 for structure.

CSS3 for styling and layout.

JavaScript for DOM manipulation, event handling, and grid generation.

Usage

Open etch-a-sketch.html in a modern web browser.

Use the slider to adjust the grid size.

Select a pen color using the color picker.

Hover over grid cells to draw.

Click the reset button to clear the grid.

Project Structure

etch-a-sketch.html - Main HTML file.

style.css - Styles for layout, grid, and controls.

etch-a-sketch.js - JavaScript logic for grid creation, drawing, and event handling.

Notes

The application is designed using only vanilla JavaScript, HTML, and CSS.

The project follows beginner-friendly coding practices consistent with foundational web development concepts.
